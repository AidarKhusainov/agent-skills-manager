# Privacy policy — Agent Skills Manager

**Last updated: October 29, 2026**

Agent Skills Manager is a skills-only instruction package. The developer does not run a backend, account database, tracking service, or telemetry endpoint for this plugin.

When you request repository discovery, ChatGPT may use GitHub tools or web browsing to read repositories. When you explicitly approve a change, Plugin Creator may save repository references, selected skill files, and pinned revision metadata in a **separate private plugin owned by you**. That collection is not included in this public source package or distributed to other users by Agent Skills Manager.

This policy describes this project, not the privacy practices of ChatGPT, OpenAI, GitHub, or other tools you choose to use. Those providers may process conversations, tool requests, and source material under their own policies. Do not share access tokens or confidential repository contents in chat.

To review or remove stored skill sources, inspect your private collection and use the host's supported plugin controls. Deleting a selection from your private collection does not necessarily delete host conversation history or provider logs.

For questions, open an issue at https://github.com/AidarKhusainov/agent-skills-manager/issues.
