# Privacy policy — Agent Skills Manager

**Last updated: October 29, 2026**

Agent Skills Manager is a stateless, skills-only instruction package. Its developer operates no backend, personal account database, telemetry collection service, or user-specific repository ledger.

Public GitHub repositories you request may be read using the host's GitHub/web tools. If you authorize a native skill installation, selected source files may be written to the persistent location provided by that runtime. If you explicitly choose and authorize a user-owned private Plugin Creator collection, selected files, repository provenance and pinned revision metadata may be maintained in that **separate** collection using `sources.json`. Nothing from an individual's collection is included in this public manager package.

ChatGPT, GitHub, Codex, Plugin Creator and the environment in which you run this plugin have their own access, retention and privacy practices. Do not submit credentials, tokens or confidential repository contents to public sources or chat without considering those providers' policies.

To inspect or remove a native skill or private-plugin collection, use the authorized host controls. Removing an installed skill does not itself erase chat history or external provider logs.

Questions: https://github.com/AidarKhusainov/agent-skills-manager/issues.
